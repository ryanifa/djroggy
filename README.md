# DJ Roggy

Website voor DJ Roggy (Rotterdam). Opzet volgt `ryanifa/passthedutchie`: statische site op
GitHub Pages, data in een GitHub Gist, beheer via `beheer.html`.

Start hier: **`SPEC-dj-roggy-website.md`** (volledige specificatie, versie 1.1).

- `reviews-dj-roggy.json` — 77 klantreviews (bron: The DJ Company), schema in spec §8
- `assets/logo/` — logo (SVG/PNG), favicon en PWA-iconen
- `assets/img/hi/` — 11 foto's op 1080–1440 px
- `assets/img/instagram/` — 43 galerijfoto's op 640 px + `captions.tsv`
